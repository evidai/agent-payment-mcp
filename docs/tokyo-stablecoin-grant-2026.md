## 2. LemonCake プロダクト概要

### 一言で
AI エージェント向け M2M（Machine-to-Machine）決済プラットフォーム。
**「AI に財布を渡して、暴走したら1クリックで止める」**

### コア機能
- **Pay Token（JWT）**: スコープ・期限・上限付きの支払い権限を AI に付与
- **USDC / JPYC 決済**: 課金 API を `/api/proxy/<serviceId>/...` で呼ぶと自動課金
- **Kill Switch**: ワンクリックでトークン即時失効（race-condition free）
- **402-first**: 予算切れで構造化エラー → AI が安全停止

### 統合済みエコシステム
- Claude Desktop / Cursor（MCP サーバー: lemon-cake-mcp v0.3.2）

### インフラ

## 7.5. v2 適合性と Embedded × デュアル通貨戦略（2026-05-20 確定）

### 課題: v2 から JPYC が消えている
v2 launch (5/22) で「USDC チャージ / JPYC チャージ メニュー削除」「v1 custody-era UI drop」を実施。補助金要件「国内発行円建てSC（JPYC等）活用」と乖離。

### 解決策: Embedded × デュアル通貨デフォルト戦略
**LemonCake = Privy embedded wallet の上に乗る薄い UX レイヤー**として再定義。

| 市場 | デフォルト通貨 | Onramp |
|---|---|---|
| 🇯🇵 日本ユーザー | **JPYC**（Polygon）| JPYC EX API + LemonCake カスタム UI（**全て embedded**）|
| 🌍 海外ユーザー | USDC（Base）| Coinbase Onramp SDK（**v2 Phase 3 で embedded 実装済**）|

### 設計原則
- LemonCake は **資金を一切保管しない**（ノンカストディ維持・FSA Q11 維持）
- Privy が embedded wallet として JPYC / USDC を保管
- 全てのチャージ UX は **LemonCake UI 内で完結**（外部リダイレクトなし）
- ユーザー視点では「LemonCake にチャージして使う」体験
- 実態は Privy wallet で、LemonCake は permit JWT 発行のみ

### v2 → 補助金事業の整合ロジック
> v1 では USDC/JPYC を並列実装し設計が複雑化。v2 でグローバル版を USDC に統一して設計をクリーンアップ。**本補助金事業では、日本市場向けの JPYC ネイティブ Embedded UX を構築**し、AI エージェント決済の日本デファクト化を狙う。

→ 「v2 削除」は **「コードベースの段階的整理」** として一貫性ある説明可能。

### Embedded JPYC Charge モーダル設計
```
[ユーザー操作]                    [LemonCake 内]
1. チャージボタン押す       →    モーダル表示（外部遷移なし）
2. ¥1,000 / ¥5,000 / カスタム選択
3. 銀行振込 or クレカ選択
4. [銀行振込] 振込先表示    ←    JPYC EX API で生成
   実銀行アプリで振込
   着金 ← polling/webhook で検知
5. [クレカ] カード情報入力 ←    JPYC EX Card API
6. JPYC が Privy wallet に着金（自動）
7. permit 90日署名（Privy signTypedData）
8. 90日間 provider が自動引き落とし
```

### 日本ユーザー摩擦の劇的軽減
| 摩擦ポイント | USDC（v2 現状）| JPYC（提案） |
|---|---|---|
| 入手経路 | Coinbase / Apple Pay | **JPYC EX 銀行振込 or クレカ** |
| 為替リスク | あり | **なし（円建て）** |
| 心理的抵抗 | ドル＝海外通貨 | **JPY＝慣れた円** |
| 確定申告 | 暗号資産（外貨建て） | **電子マネー扱いで簡素** |
| 法人経費計上 | 海外決済 | **円建て請求書発行可能** |
| freee / MF 仕訳 | 為替換算必要 | **そのまま円仕訳** |

### 補助金事業 Phase（Embedded UX 軸で再設計）
- **Phase 1（採択〜3ヶ月）**: JPYC EX API 統合、Polygon JPYC permit 実装、Privy 連携
