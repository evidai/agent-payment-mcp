```
送信 81 社
  ↓ 開封・チラ見：30-50 社
```

## 注意

### 1 通だけ follow up は OK

- 初回送信から **7 日経過** で返信なし → リマインダー 1 通だけ送る
- 「先週ご連絡したものの件、ご検討状況いかがでしょうか」程度
- それ以降は催促せず撤退

### 14 日経過で撤退

- master-contact-list の状態を `❌` に更新
- 次のバッチ（2 ヶ月後）まで放置

### 既に進行中

- `Money Forward` → 既に交渉中、進捗ない場合フォロー
- `freee` → 連携掲載スタート済 ✅、別件で関係維持
- partnership R1-R4 14 社 → 別ルート、ここに追加しない

## トラブルシューティング

→ master-contact-list の URL を更新、`正しい URL` 列を追加
